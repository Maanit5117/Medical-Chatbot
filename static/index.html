About this RAG Architecture

This application implements a production-grade Retrieval-Augmented Generation (RAG) pattern tailored for clinical knowledge extraction:

  • Document Parsing: Ingested The Gale Encyclopedia of Medicine into 3,425 semantically coherent chunks (chunk size: 1,000, overlap: 200).
  • Vector Embeddings: High-density embeddings produced via qwen3-embedding:0.6b.
  • Vector Storage: Stored and indexed in Pinecone Serverless (AWS us-east-1) with cosine similarity metric.
  • Retrieval & Synthesis: Top-K relevant passages are retrieved and injected into a constrained system prompt with gemini-3.6-flash to prevent hallucinations.

Constraint: The model is instructed to answer strictly based on retrieved context and refrain from diagnosing personal cases.
